Keyboard & file help

Click a field, then use arrows to move. Space plays/pauses. Enable Record edits to write. Z S X D C V G B H N J M = one piano octave; Q 2 W 3 E R 5 T 6 Y 7 U = the next. Notes use the chosen instrument; Enter writes a note-off, Delete clears the selected field. Instrument / effect / parameter fields take two hexadecimal digits. Notes and completed values advance one row.

Order buttons select a pattern and seek playback to its first row. Click a channel header to mute it. Save downloads the full module, including edits. Mutes are listening controls and are not saved. Open accepts ntrk only (16 MiB maximum). Existing effect planes and mixer settings are preserved but have no editor here.
